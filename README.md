# Web Design Projects

Portfolio of custom website concepts, research, design explorations, and client-ready builds.

Each concept is developed in its own branch until reviewed. The first concept is an unofficial magician-site experience inspired by interactive theatrical web design. No client affiliation or endorsement is implied.

## Keith Tyran desktop concept

On `concept/keith-tyran-magician-experience`, start a local server from the repo folder:

```powershell
python -m http.server 8722 --bind 127.0.0.1
```

Open [the desktop preview](http://127.0.0.1:8722/card-reveal-demo.html). The [continuation prompt](docs/NEXT_CHAT_KEITH_BUILD_SECTION_11_2026-11-14.md) records the Sections 01–10 checkpoint and the next build step. [Progress](docs/PROGRESS.md) and [Design Preferences](docs/DESIGN_PREFERENCES.md) hold the full project history.
